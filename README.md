# Domrim Tap

## How do I install these formulae?

`brew install domrim/tap/<formula>`

Or `brew tap domrim/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "domrim/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
